## 掲載プログラム

本書に掲載しているプログラムは次の通りです。

・「helloworld」:HELLO WORLD。

・「demo」:FCライブラリのデモプログラム。BMP画像の変換プログラムも含んでいます。

・「colortest」:BGのアトリビュート設定。

・「sp_attrib」:スプライトのアトリビュート設定。

・「hit_sp」:スプライトの衝突。

・「hit_bg」:BGの衝突。

・「apu_pulse1」:矩形波サウンドテスト。

・「jumpgame」:ジャンピングアクションゲーム。

・「shooting」:シューティングゲーム。
