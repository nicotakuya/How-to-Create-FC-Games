# 「ファミコンゲームの作り方」

自主制作の本（pdf）です。

## 本編

pdfファイルの「How-to-Create-FC-Games.pdf」が本編です。11MBもあるので、ダウンロードしてお読みください。

## 掲載プログラム

本書に掲載しているプログラムは次の通りです。

・helloworld:HELLO WORLD。

・demo:FCライブラリのデモプログラム。

・colortest:BGのアトリビュート設定。

・sp_attrib:スプライトのアトリビュート設定。

・hit_sp:スプライトの衝突。

・hit_bg:BGの衝突。

・apu_pulse1:矩形波テスト。

・jumpgame:ジャンプゲーム。

・shooting:シューティングゲーム。
